 2. ADD THIS  ->  makes www.bubblypup.lk work   [REQUIRED]
-----------------------------------------------------------

Right now www.bubblypup.lk does NOT exist. Anyone who types
"www." gets a dead page. Add:

    Type   : CNAME
    Name   : www
    Value  : cname.vercel-dns.com
    TTL    : leave default (or 3600)

If your panel refuses CNAME, use this instead:

    Type   : A
    Name   : www
    Value  : 76.76.21.21

IMPORTANT - the mistake almost everyone makes:
In the "Name" field type ONLY:      www
NOT:                                www.bubblypup.lk
Most panels add the domain for you. Typing the full name
creates a broken "www.bubblypup.lk.bubblypup.lk".
(If the records already in your panel DO show the full name,
then match that style instead.)

Nothing to do on Vercel afterwards - the domain is already
added there and waiting. Vercel checks automatically and
issues the HTTPS certificate on its own.

Time to work: usually 5-30 minutes. .lk can take a few hours.


-----------------------------------------------------------
 3. ADD THIS  ->  Google Search Console        [RECOMMENDED]
-----------------------------------------------------------

There is NO google verification record on the domain yet, so
Search Console is not set up. Without it you cannot see what
people search, or whether Google has indexed the site.

STEP 1 - get the code from Google:
    Go to     https://search.google.com/search-console
    Click     Add property
    Choose    Domain   (the LEFT box)
    Enter     bubblypup.lk
    Google shows a TXT value that looks like:
              google-site-verification=AbC123xyz...

STEP 2 - add it in the same DNS panel:

    Type   : TXT
    Name   : @        (or blank, or bubblypup.lk - match your panel)
    Value  : google-site-verification=AbC123xyz...
             ^ paste Google's exact string, not this example

STEP 3 - wait 15-30 minutes, then click Verify in Google.

NOTE: you will now have TWO TXT records on @ (the SPF one and
the Google one). That is normal and correct. Do NOT replace
the SPF record - add a second TXT record.

AFTER VERIFYING:
    - Left menu -> Sitemaps -> type  sitemap.xml  -> Submit
    - Left menu -> URL Inspection -> paste https://bubblypup.lk
      -> Request Indexing
