Update the **Appointment Management** module to support both **online reservation customers** and **walk-in/call-in customers**. Keep the existing client-side reservation process and the current six appointment slots unchanged. On the admin Appointment page, add a new **“Add Walk-In Customer”** option that allows staff to manually enter details such as **pet name, pet type (Dog/Cat), appointment time, selected service, and final price**, then submit the appointment. Once added, walk-in appointments should appear together with online reservations in the current day's appointment list, with a clear indicator showing whether the appointment is **Online Reservation** or **Walk-In**. This will allow staff to see all customers scheduled for the day from one Appointment page.

Additionally, add a separate **Reports** page for appointment and revenue reporting. The reporting page should use data from both online reservations and walk-in appointments and allow the admin to view **daily, weekly, and monthly summaries**. Reports should include the **number of appointments, total revenue, day-wise revenue, weekly revenue breakdown, and monthly total revenue**. The admin should also be able to select a date, week, or month to view the relevant report, while keeping the existing reservation customer workflow unchanged.
