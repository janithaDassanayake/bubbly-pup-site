In the Admin Portal → Appointments page → Action → Edit Appointment section, we need to add an option to manually adjust the final appointment price. Currently, the total is calculated automatically based on the selected package and additional treatments, but the admin should be able to override or adjust this amount when necessary. For example, if a customer selects the Basic Bath & Cleaning Package for Rs. 4,000, the admin may want to give a special discount and change the final price to Rs. 2,000. Similarly, if the appointment requires additional treatments, extra grooming work, or extra time, the admin should be able to increase the final price, for example from Rs. 4,000 to Rs. 5,000. Therefore, the Edit Appointment form should include a Manual Price Adjustment / Final Price field where the admin can directly enter the final amount. The system should still show the original calculated price for reference, but the manually entered final price should be used as the appointment total and final payable amount after the appointment is updated.
